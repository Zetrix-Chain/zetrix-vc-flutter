# Bulletproof Setup Guide

## Quick Start (5 steps)

### 1. Install Prerequisites

**Rust (required):**
```powershell
winget install Rustlang.Rustup
rustup update
```

**Flutter Rust Bridge CLI:**
```powershell
cargo install flutter_rust_bridge_codegen
```

**LLVM (for code generation):**
```powershell
winget install LLVM.LLVM
```

### 2. Generate FFI Bridge

```powershell
.\scripts\generate_bridge.ps1
```

This creates:
- `lib/src/bridge_generated.dart` - Dart bindings
- `rust/src/bridge_generated.rs` - Rust FFI glue

### 3. Build Rust Library

**For Android:**
```bash
# Install cargo-ndk
cargo install cargo-ndk

# Add Android targets
rustup target add aarch64-linux-android
rustup target add armv7-linux-androideabi  
rustup target add x86_64-linux-android
rustup target add i686-linux-android

# Build
cd rust
cargo ndk -t armeabi-v7a -t arm64-v8a -t x86 -t x86_64 build --release
```

**For iOS:**
```bash
# Add iOS targets
rustup target add aarch64-apple-ios
rustup target add x86_64-apple-ios

# Build
cd rust
cargo build --release --target aarch64-apple-ios
cargo build --release --target x86_64-apple-ios
```

**For Windows (testing):**
```powershell
cd rust
cargo build --release
```

### 4. Update Service to Use Bridge

After bridge generation, update `lib/src/services/bulletproof_service.dart`:

```dart
import 'package:zetrix_vc_flutter/src/bridge_generated.dart';
import 'package:zetrix_vc_flutter/src/models/bulletproof/bulletproof_proof.dart';

class BulletproofService {
  final RustImpl _bridge;

  BulletproofService(this._bridge);

  Future<BulletproofProof> generateSingleMinRangeProof({
    required int value,
    required int min,
    int bitSize = 32,
    String domain = 'zetrix-vc',
  }) async {
    final result = await _bridge.generateSingleMinRangeProof(
      value: value,
      min: min,
      bitSize: bitSize,
      domain: domain,
    );

    if (!result.success) {
      throw Exception(result.errorMessage);
    }

    return BulletproofProof(
      proofValue: result.proofValue,
      commitments: result.commitments,
      bitSize: bitSize,
      domain: domain,
    );
  }

  // ... implement other methods similarly
}
```

### 5. Test

```powershell
flutter test test\bulletproof_test.dart
```

## Usage Example

```dart
import 'package:zetrix_vc_flutter/zetrix_vc_flutter.dart';

void main() async {
  final service = BulletproofService(RustImpl());

  // Scale decimal GPA to integer
  int cgpa = BulletproofUtil.scaleDecimal(3.45, 2);      // 345
  int maxCgpa = BulletproofUtil.scaleDecimal(4.0, 2);    // 400  
  int minCgpa = BulletproofUtil.scaleDecimal(2.9, 2);    // 290

  // Generate proof for age and CGPA
  final proof = await service.generateMultipleMinMaxRangeProof(
    values: [22, cgpa],
    mins: [18, minCgpa],
    maxs: [0, maxCgpa],  // 0 = no max for age
  );

  print('Proof: ${proof.proofValue}');
  
  // Verify
  final isValid = await service.verifyMultipleMinMaxRangeProof(
    mins: [18, minCgpa],
    maxs: [0, maxCgpa],
    proof: proof,
  );
  
  print('Valid: $isValid');
}
```

## Troubleshooting

### Bridge Generation Fails

**Error:** `flutter_rust_bridge_codegen not found`

**Fix:**
```powershell
cargo install flutter_rust_bridge_codegen
# Restart terminal to update PATH
```

### Rust Build Fails

**Error:** `bulletproofs crate not found`

**Fix:**
```powershell
cd rust
cargo clean
cargo update
cargo build
```

### Runtime Error

**Error:** `UnimplementedError: Bulletproof bridge not generated`

**Fix:** Run `.\scripts\generate_bridge.ps1` first

### Android NDK Not Found

**Error:** `cargo-ndk not found`

**Fix:**
```powershell
cargo install cargo-ndk
# Install Android NDK via Android Studio SDK Manager
```

```
│   │   ├── api.rs              ← FFI API (already created)
│   │   ├── lib.rs              ← Module exports (already created)
│   │   ├── bridge_generated.rs ← Generated by script
│   │   └── bulletproof/
│   │       ├── mod.rs          ← Core logic (already created)
│   │       ├── prover.rs       ← Proof generation (already created)
│   │       └── verifier.rs     ← Proof verification (already created)
│   ├── Cargo.toml              ← Dependencies (already configured)
│   └── target/                 ← Build output
│       └── release/

│   └── src/

│       ├── services/
│       │   └── bulletproof_service.dart ← Update after generation

│       └── utils/
│           └── bulletproof_util.dart    ← Already created

    └── generate_bridge.ps1             ← Run this first
```
